# Lim Fu Yung Portfolio

This is a personal portfolio website built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in your browser, or run a local web server:

```bash
cd "D:\Bachelor Degree\Personal Project\Intro"
python -m http.server 8000
```

Then open: http://localhost:8000

## Upload to GitHub and publish live with GitHub Pages

1. Create a GitHub account and log in.
2. Create a new repository, for example: `lim-fu-yung-portfolio`
3. In your project folder, run:

```bash
git init
git add .
git commit -m "Initial portfolio website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/lim-fu-yung-portfolio.git
git push -u origin main
```

4. In GitHub, open your repository.
5. Click Settings → Pages.
6. Under Source, choose `Deploy from a branch`.
7. Select `main` and `/root` (or `/`) folder.
8. Save.
9. Wait a few minutes and your site will be published at:

```text
https://YOUR_USERNAME.github.io/lim-fu-yung-portfolio/
```

## Notes

- This site uses only plain HTML, CSS, and JavaScript.
